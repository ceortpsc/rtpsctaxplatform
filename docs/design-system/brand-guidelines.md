## Brand test

On branded first viewports, **RTPSC** (or the product name) must remain a hero-level
signal. Removing the nav should not leave a generic SaaS page.

## Do / Don’t

- **Do** use navy + gold + cool slate from `theme.css`.
- **Do** keep control-plane dark theme in the same family (not forest green).
- **Don’t** use cyan neon glows, purple-on-white gradients, or cream-only one-offs as the primary brand language going forward.
- **Don’t** invent alternate logos per service.
