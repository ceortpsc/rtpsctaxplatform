# Cards / Panels

Default stance: **no decorative cards**. Use panels only when they contain interaction
or bounded operational data.

| Surface | Class (Ross AI) | Class (ui-system) |
|---------|-----------------|-------------------|
| Panel | `.panel` | surface + border tokens |
| Module tile | `.mod` | — |
| Metric | `.metric` | — |
| Tier | `.tier` | — |

Do not place cards in marketing heroes. Prefer full-bleed atmosphere + typography.
