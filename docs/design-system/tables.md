# Tables

- Wrapper: `.table-wrap` for horizontal scroll on small screens.
- Ross AI: `table.data` for users roster.
- Prefer semantic `<table>` with `<th scope="col">`.
- Dense financial tables: mono for amounts, right-align currency.
- Empty state: muted row spanning columns — do not invent fake data.
- Status cells use text labels from `STATUS_META`, not color alone.
