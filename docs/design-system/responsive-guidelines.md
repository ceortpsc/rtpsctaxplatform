# Responsive Guidelines

- Mobile-first; collapse `.grid-2` and `.strip` under ~800px / 520px (Ross AI).
- App shell: collapse sidebar to icon rail / mobile drawer (`shell.css`).
- Tables: always wrap in `.table-wrap`.
- Touch targets ≥ 40px height for primary controls.
- Input font-size ≥ 16px (`--fs-lg`) to avoid iOS zoom.
- Test operator UIs at 360px, 768px, 1280px.
