# Elevation

| Token | Use |
|-------|-----|
| `--shadow-1` | Subtle resting panels |
| `--shadow-2` | Raised panels / gate cards |
| `--shadow-3` | Modals / drawers |
| `--shadow-gold` | Primary CTA hover emphasis |
| `--ring-focus` | `0 0 0 3px rgba(176, 137, 0, 0.35)` |

Dark theme shadows use deeper black alphas. Print / high-contrast themes set shadows to
`none`. Prefer borders (`--color-line`) over heavy multi-layer shadows.
