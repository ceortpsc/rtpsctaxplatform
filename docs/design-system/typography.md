# Typography

Defined in `packages/ui-system/public/theme.css`.

## Stacks

| Token | Stack | Role |
|-------|-------|------|
| `--font-display` | Iowan Old Style, Palatino Linotype, Book Antiqua, Palatino, Georgia, serif | Heroes, panel titles, brand |
| `--font-sans` | Avenir Next, Segoe UI Variable Text, Segoe UI, Helvetica Neue, sans-serif | UI chrome, body |
| `--font-mono` | SFMono-Regular, JetBrains Mono, Consolas, Menlo, monospace | Codes, tags, WS pills, receipts |

Avoid Inter / Roboto / Arial / system-ui as primary brand fonts.

## Scale

| Token | Size |
|-------|------|
| `--fs-xs` | 11px (0.6875rem) |
| `--fs-sm` | 13px |
| `--fs-md` | 15px |
| `--fs-lg` | 16px (minimum input text) |
| `--fs-xl` | 1.25rem |
| `--fs-2xl` | 1.625rem |
| `--fs-3xl` | 2.125rem |
| `--fs-4xl` | 2.75rem |

Line heights: `--lh-tight` 1.15, `--lh-snug` 1.35, `--lh-normal` 1.55.  
Tracking: `--tracking-wide` 0.06em, `--tracking-wider` 0.14em (eyebrows, env chips).
