# Radius

| Token | Value | Use |
|-------|-------|-----|
| `--r-sm` | 6px | Inputs, tags, chips |
| `--r-md` | 10px | Buttons, panels |
| `--r-lg` | 14px | Gate panels, large cards |
| `--r-xl` | 20px | Rare hero containers |
| `--r-pill` | 999px | Live status pills only |

Thermal / receipt mode zeros radii. Avoid decorative “pill clusters” in marketing heroes;
pills are for live status only.
