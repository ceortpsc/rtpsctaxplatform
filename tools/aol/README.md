# AOL — Adaptive Optimized Linker

First-party package manager for the RTPSC monorepo. Parallel workspace linking,
`RTPSC-package-lock.json`, and Instant Messenger–era CLI aesthetics.

```bash
./scripts/aol install
./scripts/aol run lint
./scripts/aol bench
```

Docs: `docs/aol-package-manager.md`, `docs/aol-api-and-config.md`,
`docs/aol-intellectual-property.md`.
