# Form templates (scaffold)

RTPSC tax-prep references these form ids via `@rtp/tax-prep` `FORM_CATALOG`.

Live MeF XML packs are **not** shipped here — diagnostics and interview attach document ids only until the secure tunnel and legal sign-offs are complete.

| Id | Form |
| --- | --- |
| `1040` | Form 1040 |
| `sched-a` … `sched-e` | Schedules A–E |
| `8867` | Paid Preparer Due Diligence |
| `w2` / `1099-*` | Income statements |

See `docs/pro-superiority-taxslayer.md`.
