# External Production Prerequisites

The following controls require real organizational accounts, credentials, infrastructure, or approval and cannot be completed by source generation alone:

1. Production OIDC or SAML SSO and MFA.
2. Managed secrets and key-management configuration.
3. Production domain, DNS ownership, TLS certificate, and canonical URL.
4. Approved database and persistent-storage topology.
5. WAF, rate limits, upload malware scanning, and edge protections.
6. Production email, notification, storage, identity, and webhook credentials.
7. Protected GitHub environments, branch rules, required reviewers, and deployment approvals.
8. Google Search Console and Bing Webmaster ownership tokens.
9. Legal, privacy, tax, records, accessibility, and security review by authorized professionals.
10. Backup restoration test in the target environment.
11. Incident contacts, on-call ownership, and notification procedures.
12. Production acceptance and deployment authorization by Ross Tax Pro Software Co.

The application must remain a release candidate until these items are evidenced for the target environment.
